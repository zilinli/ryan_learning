# Agent Chat Console — 前端交互与 UI 设计

> **版本**: v0.1.0 | **日期**: 2026-08-04

---

## 1. 设计目标

模仿 **Cursor IDE 的 Agent 窗口** 体验：

- 左右两栏布局：左侧对话区 + 右侧工作区
- 深色主题（类 IDE），符合开发者审美
- 对话气泡 + Markdown 渲染 + 代码块语法高亮
- 语音输入「按下录音 → 识别 → 确认 → 发送」的交互闭环
- 流式输出（逐字/逐块出现），类似终端体验

## 3. 组件详细设计

### 3.1 对话区 `ChatWindow`

**功能**:
- 消息列表（用户消息 + Agent 回复），自动滚动到底部
- 流式输出：新消息逐字出现，末尾有闪烁光标 `▊`
- Agent "思考中" 状态：三个跳动的点 `...`
- 工具调用展示：可折叠的卡片，显示工具名 + 输入/输出

**交互状态**:

```
空闲:  "输入你的命令，让 Cursor 帮你写代码..."
发送中: [用户消息] + [Agent: ... 思考中]
流式输出: [用户消息] + [Agent: 好的，我来帮你创建...▊]
完成: [用户消息] + [Agent: 完整的回复（Markdown 渲染）]
错误: [用户消息] + [Agent: ❌ 出了点问题，点击重试]
```

### 3.2 输入区 `Composer`

```
┌─────────────────────────────────────────────────────┐
│ 🎤  [语音按钮]  │ ______________________________  [发送 →] │
│                  │ 输入你想让 Cursor 做的事情...      │
│                  │________________________________ │
│                  │ Shift+Enter 换行  ·  Enter 发送   │
└─────────────────────────────────────────────────────┘
```

**三种输入模式**:

| 模式 | 触发 | 流程 |
|------|------|------|
| **文字输入** | 直接打字 | 输入 → Enter → 发送 |
| **语音输入** | 点击/按住 🎤 | 录音 → 识别 → 弹窗确认 → 发送 |
| **混合输入** | 语音后手动改文字 | 录音 → 识别 → 弹窗中修改 → 发送 |

### 3.3 语音确认弹窗 `VoiceConfirmModal`

```
┌──────────────────────────────────────┐
│         语音识别结果                  │
│                                      │
│  ┌──────────────────────────────────┐│
│  │ 帮我在 agent-chat 目录下创建一个  ││
│  │ Express.js 后端项目，包含基础     ││
│  │ 的 API 路由和中间件配置           ││
│  └──────────────────────────────────┘│
│                                      │
│  🎙️ 语言: 中文  ·  置信度: 92%      │
│                                      │
│  [ 🎤 重新录音 ]    [ ✏️ 修改文字 ]  │
│                                      │
│              [ 📤 确认发送 ]          │
│              [ ✖ 取消 ]             │
└──────────────────────────────────────┘
```

**交互流程**:
1. 用户按住或点击 🎤 按钮 → 开始录音（红色脉冲动画）
2. 释放/再点击 → 停止录音
3. 0.5-3s → 显示识别结果弹窗
4. 用户可以：
   - **修改文字**: 点击编辑，直接在文本框修改
   - **重新录音**: 点击重录，重新开始
   - **确认发送**: 将文字填入输入框并发送
   - **取消**: 关闭弹窗，丢弃识别结果

### 3.4 工作区侧边栏 `WorkspaceSidebar`

**文件树**:
```
📁 ryan_learning
 ├─ 📁 agent-chat          ← 展开
 │   ├─ 📁 docs
 │   ├─ 📁 src
 │   ├─ 📄 package.json
 │   └─ 📄 next.config.ts
 ├─ 📁 src                 ← 收起
 ├─ 📁 scripts
 ├─ 📄 package.json
 ├─ 📄 README.md
 └─ 📄 start.sh
```

**交互**:
- 点击目录 → 展开/收起
- 点击文件 → 右侧预览面板显示内容
- 文件类型图标：`📄` 普通文件、`📁` 目录、`📝` 代码文件、`🖼` 图片
- 右键菜单（可选 v1.0）：复制路径、在 Agent 中提到此文件

## 4. 视觉设计

### 4.1 色彩系统（Dark Theme）

```
背景色:
  主背景:    #1e1e2e  (深紫灰，VS Code 暗色风格)
  侧边栏:    #181825  (更暗一点)
  卡片/气泡: #313244  (中灰紫)
  输入框:    #313244

文字色:
  主文字:    #cdd6f4  (浅灰白)
  次要文字:  #a6adc8  (中灰)
  提示文字:  #6c7086  (暗灰)
  代码:      #89b4fa  (蓝，Agent 回复中)

强调色:
  主色调:    #89b4fa  (Catppuccin Blue)
  发送按钮:  #cba6f7  (紫色)
  语音录制中: #f38ba8  (红色脉冲)
  成功:      #a6e3a1  (绿色)
  警告:      #f9e2af  (黄色)
  错误:      #f38ba8  (红色)

代码块:
  背景:      #11111b  (极暗，带圆角边框)
  语法高亮:  Catppuccin Mocha 主题配色
```

### 4.2 字体

| 用途 | 字体 | 备选 |
|------|------|------|
| UI 文字 | JetBrains Mono, Source Sans 3 | system-ui |
| 代码块 | JetBrains Mono | Fira Code, monospace |
| 消息正文 | Source Sans 3 | -apple-system, sans-serif |

### 4.3 动画

| 场景 | 动画 |
|------|------|
| 消息出现 | `slide-in-bottom` 200ms ease-out |
| 流式光标 | `blink` 1s infinite |
| 思考中 | 三个点 `bounce` 500ms staggered |
| 语音录制 | 红色圆环 `pulse` 1s infinite |
| 弹窗出现 | `scale-in` 150ms ease-out |
| 侧栏展开 | `slide-in-right` 300ms ease-out |
| 文件树展开 | `collapse` 200ms ease |

## 5. 交互细节

### 5.1 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Enter` | 发送消息（输入框聚焦时） |
| `Shift+Enter` | 换行 |
| `Ctrl/Cmd+B` | 切换工作区侧边栏 |
| `Ctrl/Cmd+K` | 聚焦输入框 |
| `Escape` | 关闭弹窗/取消录音 |

### 5.2 移动端适配

```
┌──────────────────────────┐
│ ← Agent Chat Console     │
├──────────────────────────┤
│                          │
│  [Agent] 好的，我来帮... │
│                          │
│  [User] 帮我创建...      │
│                          │
│                          │
├──────────────────────────┤
│ 🎤 │ _____________ │ 📤 │
│    │ 输入命令...    │    │
└──────────────────────────┘
```

- 移动端隐藏工作区侧栏（全屏对话）
- 输入框固定底部，键盘弹起时自动上移
- 语音按钮放大，方便拇指操作
- 滚动到底部有「滚动到底」浮动按钮

### 5.3 加载与空状态

| 状态 | UI |
|------|-----|
| **首次加载（无历史）** | 居中显示 "🤖 Agent Chat Console" + 副标题 + 输入框已经可以输入 |
| **Agent 思考中** | 消息气泡里显示三个跳动的点 `... ` |
| **Agent 流式输出中** | 消息气泡不断追加内容 + 末尾闪烁光标 `▊` |
| **Agent 工具调用中** | 可折叠的工具卡片："🔧 正在执行: mkdir -p agent-chat/src" |
| **网络断开** | 输入框上方显示黄色提示条 "连接断开，正在重连..." |
| **API Key 未配置** | 全屏 Setup 面板，输入 API Key |

## 6. 组件树

```
<RootLayout>                          // 暗色主题 + 字体
  <ChatPage>
    <Header>                          // 顶部标题栏
      <Title>Agent Chat Console</Title>
      <SidebarToggle />              // 切换工作区侧栏
      <HistoryButton />              // 历史对话按钮
    </Header>
    <MainContent>
      <ChatWindow>                   // 左侧对话区
        <MessageList>
          <MessageBubble role="user" />
          <MessageBubble role="agent" />
          <StreamingMessage />       // 流式输出中的消息
          <ToolCallCard />           // 工具调用折叠卡片
        </MessageList>
        <ScrollToBottomButton />
      </ChatWindow>
      <WorkspaceSidebar>             // 右侧工作区
        <FileTree />
        <FilePreview />
      </WorkspaceSidebar>
    </MainContent>
    <Composer>                       // 底部输入栏
      <VoiceButton />               // 语音输入按钮
      <TextInput />                 // 文字输入框
      <SendButton />               // 发送按钮
    </Composer>
    <VoiceConfirmModal />            // 语音确认弹窗（条件渲染）
    <SetupPanel />                   // API Key 设置（条件渲染）
  </ChatPage>
</RootLayout>
```

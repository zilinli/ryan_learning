# 方言回归测试集（Dialect Eval Set）

> 面向 Spark AI Tutor 的潮汕话 / 客家话书面方言模式
> 用途：每次修改 prompt 或词典后，人工过一遍下面句子，检查方言输出是否仍然"像话"
> 打分：1（完全不像话）– 5（母语者听起来很自然），记录到 `data/dialect-eval-set-scores.jsonl` 或备注在本文档

## 使用方式

1. 在 Spark 中把语音切换为对应方言模式（Teochew / Hakka），或用 `/api/chat` 直接发同样的用户消息。
2. 检查三件事：
   - **词汇**：是否用上了词典中的高频方言词（个 / 唔 / 食 / 涯 / 做得 等）。
   - **语法**：语序是否像口头方言（客家话副词前置如「先行」；潮汕话短句为主）。
   - **渲染**：是否出现 CJK 扩展区生僻字（𠊎、摎 等），出现即视为造字失败。
3. 记录每题得分；平均分下降 0.5 分以上需要回滚 prompt 改动。

## 通用红线检查（两种方言都适用）

- [ ] 不出现 CJK 扩展区生僻字（如 𠊎、摎）；客家话「我」只写「涯」。
- [ ] 不整段照抄 prompt 里的 few-shot 示例内容。
- [ ] 数学公式保持 LaTeX，不被方言改写。
- [ ] 每条回复至少出现 1 个高频方言词（个 / 唔 / 食 / 做得 等）。
- [ ] 没有普通话整句直接照搬（如"我们一起做题吧"未做任何方言化）。

# Learning Games v2 — 视觉与游戏设计升级

> Version 0.1 · 2026-08-14 · **Design only — no code until confirmed**
> Scope: 重新设计 `/entertain` 全部六款 Learning Games 的**游戏设计与 UI**，
> 解决"对现在的小孩吸引力不足、显得幼稚"的问题。
> 前身: [learning-games.md](./learning-games.md)（实现记录）、[physics-learning-games.md](./physics-learning-games.md)（物理游戏 P0-P2 设计）。

---

## 0. 一句话结论

现有六款游戏是**"带练习的玩具"，不是"会教的游戏"**。问题不在题材（分数/力/生态/历史都不错），而在四个层面：

1. **视觉语言幼稚** —— emoji 当图标、贴纸感、卡通渐变。
2. **奖励结构外部化** —— 分数 + 星星 + streak + 收藏，靠"投喂"留人，缺乏内在动机。
3. **反馈缺失** —— 没有 juice（hit-pause / 粒子 / 音效 / 触觉），操作像"表格在动"。
4. **世界观缺席** —— 卡片化布局像表单，没有空间感、剪影、节奏与张力。

升级方向不是"更花哨"，而是**更克制、更现代、更有质感**：把学习目标藏进游戏张力里，用一套统一的设计语言让六款游戏看起来是"同一个世界里的六个关卡"。

## 1. 问题诊断（为什么显得幼稚）

对照现有代码逐条列证据（`src/components/*Game.tsx`）。

| # | 症状 | 现有证据 | 为何显得幼稚 |
|---|------|----------|--------------|
| 1 | emoji 当核心图标 | `🚀🌍📜⚓⚡🪐` 大字号渲染，TimeVault 用 `📜` 做 `animate-pulse` 加载态；"Seal the case 🔒"、"Case closed 🕵️" | emoji 是"贴纸/表情包"语汇，是幼儿教育 app 的强信号，不是游戏的世界观 |
| 2 | 外部奖励堆砌 | `Score +10/+20`、`⭐ stars`、`streak`、`artifacts`、`Docks lit`、`Chains`、`Shards` 各自计数 | 靠分数/收藏"投喂"，孩子玩两轮就腻；缺乏"我想再试一次"的内在理由 |
| 3 | "你真棒"式文案 | "Great thinking"、感叹号 + emoji 结尾、`✓/✗` 贴纸 | 把用户当"宝宝"表扬，而非把结果当"信息"反馈 |
| 4 | 卡片化布局像表单 | 任务卡 + 按钮堆叠（"Predict & run"、"Next dock"），无游戏世界 | 阅读-答题-点按钮的节奏，是练习册不是游戏 |
| 5 | 无 juice | 无 hit-pause、无粒子、无音效、无触觉、无 spring 回弹 | 操作像"电子表格在动"，缺少"世界回应我"的瞬间 |
| 6 | 无失败戏剧性 | 错了只是红字/`✗`/卡片弹回，无屏幕反应 | 失败应该是"世界对我的动作的回应"，而不是判卷 |
| 7 | 色彩两极化 | EcoGenesis 浅绿 `#eef6ef` + 卡通渐变天空；TimeVault 古铜 `#1f1710` | 要么甜腻低龄，要么沉闷老气，都没有现代游戏的"深底 + 单主色 + 高对比" |
| 8 | 教程靠文字 | "Tap a card to link its evidence"、"Tap a dock to predict" | 文字教学 = 默认用户看不懂；好游戏让可交互元素自己"发光" |

## 2. 调研综述

### 2.1 "幼稚感"的真相

**简单不等于幼稚。** Roblox / Minecraft 的低多边形与像素风是刻意的艺术选择，孩子喜欢它们不是因为"图形好"，而是因为 **vibe、自主性、创意自由、社交**（NewZoo GDC 2026：这一代"追逐画质"基本结束，孩子要的是氛围与掌控感）。研究一致指出：

- 饱和、扁平、明亮的卡通**吸引**儿童，但"卡通"不等于"幼教"；幼儿教育 app 的"幼稚"来自**拟人 mascot + 彩虹贴纸 + 表扬文案 + 外部奖励套路**，而非简单几何。
- 简单是**功能**：可读性高、低端设备可跑、迭代快、把注意力留在"玩"本身。

> 结论：Ryan（9 岁，G4）会看 Roblox / Minecraft / Brawl Stars / Among Us。它们共同点是——**有个性的世界观 + 干净的 HUD + 有反馈感的操作 + 不幼稚的幽默**，而非"高保真"。

### 2.2 好益智游戏的设计（Monument Valley / BABA IS YOU）

| 案例 | 关键设计 | 对我们的启示 |
|------|----------|--------------|
| **Monument Valley** | 功能即美学（beauty made functional），无纯装饰；隐式教程（implicit onboarding）；短关卡自包含；剪影与留白；"一个画面看到整个世界" | 删掉一切不服务玩法/学习的元素；第 1 关不弹文字，让可点元素发光；每关 30–60 秒 |
| **BABA IS YOU** | 约束即内容引擎：少动词 → 深关系；规则可视化、完美信息；失败是信息不是惩罚 | 每款游戏只保留 1–2 个动词；把"知识点"做成可见的规则；无限重试 + 具体反馈 |
| **Tetris**（反例校准） | juice 匹配审美：一行消除只给短暂闪线 + 轻音，不撒粒子 | 学习类游戏要**克制的 juice**，别用过量粒子打断认知流 |

### 2.3 UI 与 game feel（STEM Case / PowerZ / 儿童 UX / Roblox GUI）

- **STEM Case UI Redesign（12–18 岁）**：teal/cyan 高对比现代配色（而非"喊叫"原色）、玻璃拟态、圆角 + 分层边框 + 对角线 cut-in、先做黑白稿再上色。
- **PowerZ（儿童）**：chunky 可读但 minimal 轻盈，动画让界面"活"，信息分级消化。
- **Child vs Adult UX**：目标导向、一次一个任务、一致性（按钮颜色/形状稳定）、图标贴近真实、`彩色可以亮但不能滥`。
- **Roblox GUI 工程规范**：网格对齐、正文对比度 ≥ 4.5:1、核心操作 ≤ 3 击、触控目标 ≥ 48px。
- **Juice（Socratopia / game feel）**：juice = 同步的视听触反馈（粒子/震动/hit-pause/音效/触觉），把"按下按钮"变成"世界回应我"；必须 sample-accurate 同步（误差 < 50ms）；用物理动画（spring-damping / cubic-bezier）而非生硬 tween。

## 3. 设计原则（7 条）

1. **功能即美学** —— 无纯装饰；每个像素要么服务玩法，要么服务学习。
2. **隐式教程** —— 第 1 关不解释；可交互元素发光/微动，玩家通过"做"学会，而非通过"读"。
3. **学习即张力** —— 知识点藏进"必须做对才能推进"的冲突里（燃料不足到不了 / 链断了熄灯 / 推过头撞墙）。
4. **短关卡** —— 30–60 秒一个 loop，一坐能完成 3–5 关，随时可停。
5. **失败是信息不是惩罚** —— 弹回 + 无限重试 + 具体反馈；没有 Game Over。
6. **内部动机优先** —— 进度 = 关卡地图节点（世界推进），弱化分数/星星/streak。
7. **juice 匹配审美** —— 克制的同步反馈（hit-pause + spring + 分层音效 + 触觉），学习态不撒粒子。

## 4. 统一设计语言系统（Design Tokens）

六款游戏共用一套 token，让它们看起来是"同一个世界"。

### 4.1 色彩

全局：**深色底 + 单主色强调 + 低饱和中性 + 高对比**。深底带色相（非纯黑），主色用于"可交互/正确/能量"，错误用统一的警示色。对比度正文 ≥ 4.5:1。

| Token | 值（建议） | 用途 |
|-------|-----------|------|
| `surface-0`（底） | 各游戏专属深底（见下） | 全屏背景 |
| `surface-1`（卡片） | 底 + 8% 白 | 面板/卡 |
| `stroke` | 白 12–16% | 分隔线/边框 |
| `accent`（主色） | 各游戏专属 | 可交互/正确/能量 |
| `danger` | `#f87171`（珊瑚红） | 错误/碰撞/断链 |
| `text-hi` / `text-lo` | `#e6e9ef` / 60% 白 | 主/次文本 |
| `success-glow` | 主色 40% 发光 | 正确反馈 |

各游戏专属底 + 主色（现代、低饱和、深底单色）：

| 游戏 | 底 `surface-0` | 主色 `accent` |
|------|----------------|---------------|
| Fraction Voyager | `#0a0f1a` 深空蓝黑 | `#4da3ff` 青蓝 |
| Force Bay | `#0b1210` 深青黑 | `#2dd4bf` teal + `#fb7185` 反向珊瑚 |
| Energy Chain | `#120f08` 深暖黑 | `#fbbf24` 金黄 |
| Orbit Scout | `#0b0d14` 深雾黑 | `#a78bfa` 雾紫 |
| Eco Genesis | `#0c1410` 深叶黑 | `#34d399` 叶绿 |
| Time Vault | `#161009` 深暖灰 | `#d4a15c` 琥珀 |

### 4.2 图标：SVG 几何符号替代 emoji

emoji 全部替换为**线性 SVG 几何符号**（stroke 1.5，圆角，单主色）。映射：

| 旧 emoji | 新几何符号 | 语义 |
|----------|-----------|------|
| `🚀` | 低多边形飞船（三角 + 尾焰线） | 分数远航 |
| `⚓` | 力矢量箭头（带方向） | 力湾 |
| `⚡` | 断点电路节点 | 能量链 |
| `🪐` | 剪影圆 + 轨道环 | 巡轨 |
| `🌍` | 低多边形等距生态缸 | 生态创世 |
| `📜` | 编号档案卡（几何） | 时空档案 |
| `🔒📎✓✗` | 状态用小圆点 / 对勾几何线 | 通用状态 |

### 4.3 形状与字体

- 圆角 10–16px，卡片**分层边框**（外细内粗，可选对角线 cut-in）营造"立体感"而非"贴纸感"。
- 玻璃拟态仅用于顶部 HUD（`backdrop-blur`），游戏主体保持扁平剪影。
- 字体：无衬线，层级清晰（标题 `--font-display`、正文系统无衬线）；数字一律 `tabular-nums`；**禁用装饰性/手写体**。

### 4.4 触控与布局

- 主操作放底部拇指区；触控目标 ≥ 48×48px；移动优先。
- 顶部 HUD：进度 + 返回，无分数大字；底部：唯一主 CTA（"下一步"而非"Predict & run"式按钮堆叠）。
- 网格对齐（参照 Roblox GUI 规范），核心操作 ≤ 3 击。

### 4.5 动效与 juice

时长分级：**150ms 反馈 / 300ms 转场 / 500ms 结算**。缓动用 spring-damping 或 `cubic-bezier(0.22, 1, 0.36, 1)`，禁止线性 tween。

| 事件 | juice |
|------|-------|
| 正确 | 主色短暂发光 + 轻 `hit-pause`（~80ms 冻结）+ 一个向上小粒子 + 成功音 + 轻触觉 |
| 错误 | 元素弹回（spring）+ 屏幕微震（1–2px，仅碰撞类）+ 错误音（低音）+ 中触觉 |
| 中性点击 | 150ms 下压回弹 + 轻触觉 |
| 结算 | 500ms 关卡地图节点点亮 + 短旋律 |

**学习态克制**：分数/排序/推理类（Voyager / TimeVault）用"确认但不打断"的 juice（类比 Tetris），碰撞/断链类（Force Bay / Energy Chain）可用更重的反馈。

### 4.6 音效与触觉（可后置）

- 音效：短促、分 pitch —— 成功高音、错误低音、点击中性、结算短旋律；音量低。
- 触觉：`light`（确认）/ `medium`（成功）/ `heavy`（错误/碰撞）三层；与视觉 sample-accurate 同步（< 50ms）。
- 依赖 app 现有 TTS/音频基础设施，可降级为静音（视觉 juice 独立成立）。

## 5. 六款游戏逐一重设计

每款给出：现状问题 → 世界观/幻想 → 核心 loop 微调 → UI 方向。

### 5.1 Fraction Voyager 分数远航

- **现状**：`🚀` + 星星 + 数字线 + 任务卡。
- **幻想**：星际领航仪。飞船 = 低多边形几何体；数字线 = 发光的能量轨道。
- **核心张力**：分数 = 燃料量，落错位置 = 飘出轨道弹回。
- **UI 方向**：深空蓝黑底 + 青蓝主色；飞船与轨道用 SVG；第 1 关只给一条轨道 + 可拖飞船，点击发光节点吸附（隐式教程）。
- **改动清单**：去 emoji 与星星计数 → 轨道发光 + 飞船 SVG；分数改为"航段推进"；加入命中发光 + 弹回 spring。

### 5.2 Force Bay 力湾

- **现状**：`⚓` 码头按钮 + "← Left / Right →"文字按钮 + 强度 chevron 按钮。
- **幻想**：矢量船坞。力箭头 = 发光的矢量线，**方向 + 强度 = 一次拖拽**（拖得越长力越大）。
- **核心张力**：推不足停在半路、推过头撞墙（屏幕微震 + hit-pause）。
- **UI 方向**：深青黑底 + teal 主色（方向）/ 珊瑚（反向碰撞）；码头 = 剪影；去掉文字方向按钮，改成拖拽箭头（更接近游戏）。
- **改动清单**：方向按钮 → 拖拽矢量；`Predict & run` → 单一 CTA；碰撞失败加屏幕微震。

### 5.3 Energy Chain 能量链

- **现状**：文字瓷砖（"Height/Motion/Bell"）+ "works/fails"按钮。
- **幻想**：能量回路板。节点 = 发光几何图标；能量 = 沿链流动的粒子。
- **核心张力**：链断 = 粒子在断点熄灭（能量"用尽"可视化）。
- **UI 方向**：深暖黑底 + 金黄能量流；节点发光；粒子沿链流动演示转换。
- **改动清单**：文字瓷砖 → 几何节点；加入能量粒子流动动画；断链处粒子熄灭 + 错误音。

### 5.4 Orbit Scout 巡轨

- **现状**：`🪐` + "H1/H2"高度按钮 + 文字。
- **幻想**：极简星空 diorama（Monument Valley 式"小世界"）。星球 = 剪影圆；引力 = 恒定向下的柔和光晕。
- **核心张力**：上推过高飘出屏幕、过低落回；剪影构图。
- **UI 方向**：深雾黑底 + 雾紫主色；大留白 + 剪影；引力方向用光晕而非文字。
- **改动清单**：高度按钮 → 拖拽上推（强度 = 拖拽长度）；去 emoji；加入落回/飘出的 spring 反馈。

### 5.5 Eco Genesis 生态创世

- **现状**：浅绿卡通渐变天空 + emoji 物种卡。
- **幻想**：低多边形等距生态缸 diorama。物种 = 几何剪影；种群 = 柔和柱状光条。
- **核心张力**：食物链断 = 物种**褪色消失**（已有，加强戏剧性：消失时轻微溶解 + 灰白）。
- **UI 方向**：深叶黑底 + 叶绿主色；玻璃生态缸边框；物种用几何剪影。
- **改动清单**：浅绿卡通渐变 → 深底 diorama；emoji 物种 → 几何剪影；灭绝加溶解动画 + 错误音。

### 5.6 Time Vault 时空档案

- **现状**：`📜` 古铜 + emoji 事件卡 + "Seal the case 🔒"。
- **幻想**：扁平档案局 / 暗房。事件 = 编号几何卡（无 emoji）。
- **核心张力**：排序错 = 卡片弹回 + 时间线缺口闪烁。
- **UI 方向**：深暖灰底 + 琥珀主色；卡片用编号 + 几何图形；去 emoji 与 🔒/🕵️ 文案。
- **改动清单**：emoji 事件卡 → 编号几何卡；去掉 emoji 结尾文案；弹回 + 缺口闪烁反馈。

## 6. 落地与验收

### 6.1 分阶段

| 阶段 | 内容 | 风险 |
|------|------|------|
| **P0 基础设施** | 统一 token（色/形状/字体/触控）、SVG 图标库、juice 原语（spring / hit-pause / 粒子 / 音效 / 触觉） | 低 —— 纯前端，不碰 BKT |
| **P1 逐款重做 UI** | 按 §5 顺序：Voyager → Force Bay → Energy Chain → Orbit Scout → Eco → Time Vault | 中 —— 组件重写，保留现有 `src/lib/entertain/*` 纯逻辑与 BKT 调用不动 |
| **P2 音效/触觉** | 分层音效 + 触觉（可降级静音） | 中 —— 依赖音频基础设施 |

**关键约束**：`src/lib/entertain/*`（纯逻辑 + 测试）与 `recordStudioLearningTurn`（BKT 归因）**保持不动**；只改 `src/components/*Game.tsx` 与统一 token。学习数据模型零变化。

### 6.2 验收标准（每款）

- [ ] 无 emoji 作为图标/文案
- [ ] 深底 + 单主色 + 对比度 ≥ 4.5:1
- [ ] 第 1 关隐式教程（无文字弹窗）
- [ ] 每关 30–60 秒，核心操作 ≤ 3 击
- [ ] 正确/错误有同步 juice（hit-pause / spring / 音效 / 触觉至少其一）
- [ ] 失败 = 弹回 + 具体反馈，无 Game Over
- [ ] 触控目标 ≥ 48px，375px 宽度可用
- [ ] 进度显示为关卡地图节点，弱化分数/星星
- [ ] BKT 归因与 `src/lib/entertain/*` 纯逻辑不变

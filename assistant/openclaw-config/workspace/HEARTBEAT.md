# 心跳检查清单（30 分钟一次，轮换执行）

收到心跳轮询时，从下面按需检查，避免每次都全部执行。用 `memory/heartbeat-state.json` 记录上次检查时间，避免重复。

## 每次轮换做 2-4 项（以下均轻量）

1. **系统健康**（每天 1-2 次）
   - 电池电量：`pmset -g batt`
   - 磁盘空间：`df -h / | tail -1`
   - 磁盘剩余 < 10% 或有异常，主动提醒用户。

2. **天气**（每天早晚各 1 次）
   - `curl -s "wttr.in/?format=%l:+%c+%t+%w"` 或 `wttr.in/深圳`。
   - 仅当天气突变（降温/降雨）或用户今天明显要出门时主动推送。

3. **定时任务检查**（每周 1-2 次）
   - `openclaw cron list` 查看是否有任务失败或已过期。

4. **记忆整理**（每 2-3 天 1 次）
   - 读取最近 2-3 天 `memory/YYYY-MM-DD.md`，把值得长期保留的内容折叠进 `MEMORY.md`。
   - 用 `openclaw memory status` 检查索引健康，必要时 `openclaw memory index`。

5. **任务目录巡检**（每周 1 次）
   - `ls ~/tasks` 检查是否有超过 30 天未动的任务目录，提醒用户是否清理（用 `trash`）。

## 主动联系用户的条件（否则保持安静 HEARTBEAT_OK）

- 磁盘剩余 < 10%、电量 < 20%。
- 天气明显变化且对用户出行有影响。
- 定时任务连续失败。
- 距离上次主动说话 > 8 小时，且以上有值得说的内容。

## 安静时段

- 23:00 - 08:00 不做任何主动推送（除非紧急：磁盘满、电量告急）。
- 用户明确说"别打扰"时停止主动推送一天。

# Cost Tracker（费用记账）

利用 openclaw.json 里各模型的 cost 字段（每百万 token 单价），把每次任务的大致花费记下来，形成可追溯的月账单。

## 记录方法

任务完成后（尤其 Cursor/长对话/深度研究等烧 token 的任务），估算并追加记录：

```bash
mkdir -p ~/openclaw-costs
cat >> ~/openclaw-costs/$(date +%Y-%m).csv <<'EOF'
日期,时间,任务,模型,输入tokens,输出tokens,预估费用(元)
$(date +%F),$(date +%H:%M),<任务名>,<模型id>,<in>,<out>,<费用>
EOF
```

## 费率参考（openclaw.json 中已配置，每百万 token 元）

| 模型 | 输入 | 输出 | 缓存读 |
|---|---|---|---|
| deepseek-v4-flash | 0.14 | 0.28 | 0.028 |
| deepseek-v4-pro | 1.74 | 3.48 | 0.145 |
| qwen3.5-plus | 见百炼控制台 | 同左 | - |

费用估算公式：`费用(元) = 输入/1e6 * 输入单价 + 输出/1e6 * 输出单价`。
token 数无法精确获取时，按"任务复杂度和时长"估算量级（轻聊 2-5k / 中度任务 10-50k / 深度研究 50-200k），并在 CSV 备注列标"估算"。

## 汇总回答

- 用户问月花费：读当月 CSV，`python3` 或 `awk` 求和，按任务类型归类，微信列表回复。
- 用户问日花费：过滤当天行求和。

## 规则

- 记录要轻，不要每次聊天都记账（成本>收益）；只在明显的大任务或用户要求时记录。
- 记账是估算，注明"估算"字样，避免误导。
- 账单文件可纳入 `~/tasks` 的检索范围（memory-rag 已把 `~/tasks` 加入索引，可把费用文件放 `~/tasks/costs/` 便于检索）。
